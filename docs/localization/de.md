## Address and style
- Informal "du", as macOS German UI does; lowercase "du/dein".
- Titles and menu items: German sentence case (nouns capitalized only).
- Alerts "Clipsy can't X" → "Clipsy kann … nicht …".
- "You can't undo this (action)." → "Diese Aktion kann nicht widerrufen werden."
- Settings paths: "unter „A“ › „B“".

## Punctuation
- Quotes „…“.
- Ellipsis "…" with a space before it in menu items and buttons (Apple German: "Umbenennen …").
- Path separator "›" kept with spaces.
- Plurals: one, other (CLDR de).
